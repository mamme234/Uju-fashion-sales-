# 👗 Uju fashion sales- Premium Fashion E-Commerce

A complete fashion e-commerce website with full frontend and backend implementation.

## ✨ Features

### 🛍️ Customer Features
- Browse Products with Categories
- Search & Filter Products
- Shopping Cart & Wishlist
- User Authentication (Register/Login)
- Order Management
- Product Reviews & Ratings
- WhatsApp & Instagram Integration
- Responsive Design

### 🛠️ Admin Features (Coming Soon)
- Dashboard with Analytics
- Product Management
- Order Management
- Customer Management
- Coupon System
- Banner Management

## 🚀 Tech Stack

### Frontend
- HTML5, CSS3, JavaScript
- Font Awesome Icons
- No frameworks - Vanilla JS

### Backend
- Node.js + Express.js
- MongoDB + Mongoose
- JWT Authentication
- Cloudinary for Images
